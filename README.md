# portfolio

Faiza Munir — Software Engineering Student & Full Stack Developer portfolio.

Built with Next.js, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
